# Oil Sales Assignment (AI/ML)

تحليل بيانات مبيعات الزيوت + تنظيف + EDA + موديل بسيط + تقرير.

## الملفات

- `oil_sales_analysis.py` : الكود الكامل
- `data/oil_sales_assignment_dataset.csv` : ملف الداتا (حطه أنت هنا)
- `report.md` : مسودة التقرير
- `outputs/` : الرسومات والنتائج بعد التشغيل

## التشغيل

1. حط ملف الداتا هنا:

```text
oil-sales-assignment/data/oil_sales_assignment_dataset.csv
```

2. ثبّت المكتبات:

```bash
pip install -r requirements.txt
```

3. شغّل التحليل:

```bash
python oil_sales_analysis.py
```
